# Conductor 交互设计文档

## 1. 设计原则

- 菜单栏优先：常用操作不离开当前工作环境。
- 状态明确：用户始终能知道 sing-box 是否运行以及最近一次错误。
- 低风险操作：启动和停止前后展示结果，不静默修改公司 VPN。
- 信息渐进：默认显示状态，详细日志按需打开。

## 2. 信息架构

```text
菜单栏图标
├── 状态区
├── 启动 / 停止
├── 重新检查配置
├── 打开控制面板
└── 退出

控制面板
├── 配置
│   ├── VLESS 节点
│   ├── SOCKS5 / HTTP 出口
│   └── 流量绑定
├── 公司 VPN
│   ├── OpenVPN
│   ├── EasyConnect
│   ├── aTrust
│   └── 公司网段
├── 设置
│   ├── sing-box 检查
│   ├── 配置文件入口
│   └── 历史配置
└── 日志
    ├── 摘要和筛选
    └── 原始日志
```

控制面板顶部使用 `配置 / 公司 VPN / 设置 / 日志` 分段导航。窗口底部或工具栏固定显示运行状态、当前主要绑定摘要和启动/停止按钮，切换页面时不消失。

### 2.1 控制面板框架

```text
┌──────────────────────────────────────────────────────────────┐
│ Conductor       [配置] [公司 VPN] [设置] [日志]              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                       当前页面内容                            │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ ● 代理运行中   ChatGPT → VPS             [停止代理]          │
└──────────────────────────────────────────────────────────────┘
```

- 顶部导航使用 macOS 分段控件，选中项同时具有背景和文字差异。
- 底部状态栏左侧显示状态，中部显示主要路由摘要，右侧放唯一的启停主按钮。
- 启动中、停止中和检查中显示进度图标并禁用重复操作。
- 状态栏错误摘要可点击，点击后切换到日志页并选中 Warning/Error。
- 窗口关闭只隐藏控制面板，不停止 sing-box；真正退出应用时若代理运行，需要先提示将停止代理。

## 3. 菜单栏状态

### 未运行

显示：`Conductor 未运行`

操作：

- `启动代理`
- `检查配置`
- `打开配置`
- `退出`

### 启动中

显示：`正在启动…`

启动按钮禁用，避免重复启动。若进程在超时时间内没有进入运行状态，转为异常状态并显示最近错误。

### 运行中

显示：`代理运行中`

操作：

- `停止代理`
- `重新检查配置`
- `查看日志`
- `代理出口`
- `打开配置`
- `退出`

### 配置错误

显示：`配置错误`

展示最近一次 `sing-box check` 错误摘要，例如：

```text
配置检查失败：DNS server 字段不兼容当前 sing-box 版本
```

操作：

- `打开配置`
- `重新检查配置`
- `查看详细错误`

## 4. 启动流程

```text
用户点击“启动代理”
  ↓
检查 sing-box 路径
  ↓
检查配置文件
  ↓
执行 sing-box check
  ├─ 失败 → 展示错误，不启动
  └─ 成功
       ↓
启动 sing-box run
       ↓
检测进程和 TUN 日志
       ├─ 成功 → 显示“代理运行中”
       └─ 失败 → 显示错误并保留日志
```

启动操作不自动启动、停止或重连 OpenVPN、EasyConnect、aTrust。

## 5. 停止流程

用户点击“停止代理”后：

1. 菜单显示 `正在停止…`。
2. 向由 Conductor 记录的 sing-box PID 发送终止信号；必要时通过 macOS 管理员授权执行。
3. 等待进程退出。
4. 更新为 `Conductor 未运行`。
5. 如果进程未退出，展示“无法正常停止”，允许用户查看日志。

停止只针对 Conductor 自己记录的 sing-box 进程，不通过名称杀掉其他代理客户端。

## 6. 配置页面

页面顶部提供“添加代理出口”按钮，点击后选择：导入 VLESS、添加 SOCKS5、添加 HTTP 或添加混合端口。

完整线框：

```text
配置                                            [+ 添加代理出口]
管理代理出口以及哪些流量使用它们

代理节点
┌ VLESS ──────────────────────────────────────────────────────┐
│ VPS                                      ● 196 ms   [启用]  │
│ 198.***.***.231:21001                                      │
│ ChatGPT 应用 · OpenAI/ChatGPT 域名                          │
│                                        [测试] [编辑] […]    │
└─────────────────────────────────────────────────────────────┘

本地代理出口
┌ SOCKS5 ─────────────────────────────────────────────────────┐
│ VPN 工具 01                              ● 可连接   [启用]  │
│ 127.0.0.1:7890                                             │
│ Google 域名                                                 │
│                                        [测试] [编辑] […]    │
└─────────────────────────────────────────────────────────────┘
```

配置以卡片展示。卡片包含协议标识、名称、脱敏地址、健康状态、流量绑定摘要，以及测试和编辑操作。参考 V2BOX 的协议标签、节点卡片、延迟和快捷编辑，但使用适合 macOS 的紧凑布局，不照搬移动端底部导航。

VLESS 示例：

```text
VLESS  VPS                         196 ms
198.***.***.231:21001
绑定：ChatGPT 应用 + OpenAI 域名
[已启用]                      [测试] [编辑]
```

本地代理示例：

```text
SOCKS5  VPN 工具 01                可连接
127.0.0.1:7890
绑定：Google 域名
                              [测试] [编辑]
```

编辑流量范围时支持指定应用、指定域名、指定 IP/CIDR。全局模式放在高级选项，并在保存前提示默认出口和公司 VPN 可能受到影响。

`…` 菜单包含复制脱敏摘要、停用和删除。删除前展示受影响的绑定规则；运行中禁用停用、编辑和删除。

“添加代理出口”使用小型菜单：

```text
导入 VLESS URL…
添加 SOCKS5 出口…
添加 HTTP 出口…
添加混合端口…
```

VLESS 导入表单包含名称、VLESS URL、目标应用和解析后的脱敏预览。SOCKS5/HTTP/混合端口表单包含名称、`IP/主机:端口`、可选认证和流量范围。保存按钮只有在字段校验通过时可用。

当前 VLESS 导入支持 TCP/Reality、`encryption=none` 和无 TCP 伪装头；不支持的传输类型或 URI 参数会明确报错，保留原配置。URI 的片段名称不用于修改出口标签。

认证为可选项，用户名和密码需同时填写；密码以安全输入框显示，编辑时读取已有认证字段。混合端口使用当前输入的认证信息探测，修改认证信息后须重新探测。认证信息保存在本机配置中；HTTP Basic 和 SOCKS5 用户名密码认证本身不加密。

新增出口的名称不能与已有出口重复；修改已有出口须从其配置卡片进入编辑，以便正确回填认证信息和其他表单字段。

选择“混合端口”后，保存区显示协议探测步骤：

```text
协议探测
HTTP CONNECT      ✓ 可用
SOCKS5 CONNECT    ✓ 可用
SOCKS5 UDP        ✕ 不支持

实际出口：SOCKS5（仅 TCP）
UDP/443：快速拒绝并回退 TCP
```

探测中禁用保存和重复探测。HTTP 与 SOCKS5 TCP 均失败时不允许保存，提示检查代理连接和端口后重试；两者均成功时优先使用 SOCKS5。当前界面展示各协议成功或失败，不区分失败的具体原因。卡片协议标签显示最终生成的 `SOCKS5` 或 `HTTP`，旁边以次级标签显示“由混合端口探测”。不能把 `MIXED` 展示成 sing-box 的实际出口类型。

代理表单预填 `127.0.0.1:7890` 和“剩余流量”，但名称仍由用户填写，界面不把该端点绑定为 FastLink 专用配置。用户可以选择本机 VPN `.app`，界面展示扫描到的联网进程；保存后为这些进程生成 `direct` 排除规则。未选择应用时显示红色代理回环警告。普通端口测试成功只表示 TCP 可达；混合端口必须完成应用层 HTTP/SOCKS5 探测。

实际协议仅支持 TCP 且流量范围为“剩余流量”时，表单显示橙色说明：“该出口不支持 UDP；Conductor 将拒绝 UDP/443，使浏览器快速回退到 TCP。其他 UDP 流量不会自动改走未知出口。”

空状态显示用途说明以及唯一的“添加代理出口”主按钮，不显示空白列表。

### 操作优化实施记录（2026-11-03）

控制面板显式使用 `defaultLaunchBehavior(.presented)`，应用启动时呈现主窗口；关闭窗口后仍可通过菜单栏或 Command-0 再打开。该设置已由当前 SDK 接口与构建验证，完整重启后的窗口行为仍需实际观察。

配置页提供“刷新”，重新读取磁盘配置与历史。运行期间提示列表展示磁盘配置，外部修改需重启代理生效；刷新本身不重启代理。设置页按“运行时版本检查 → 配置检查”的顺序执行，版本检查失败时保留错误，检查期间禁止重复点击。Debug 设置页支持选择本次会话使用的 sing-box 文件，版本不低于 1.14.0 才切换。

HTTP/SOCKS5 卡片可编辑地址和简单域名、IP/CIDR、应用路径范围，自动带入已有字段及防回环进程；切换剩余流量时保留其他显式范围。混合端口重新编辑时保留探测模式。ChatGPT VLESS 卡片打开 URL 更新表单，支持从剪贴板粘贴并提示替换和备份；其他高级 VLESS 配置仍通过配置文件维护。

编辑已有出口时，清空并保存所选范围会移除该范围的简单规则，保留其他范围及组合条件规则；如原出口承接剩余流量，切换范围会提示其恢复直连。新建出口的非默认范围必须至少有一个目标。

探测和保存时锁定输入及关闭操作；无效端点显示格式和端口范围提示。保存、删除成功后显示 5 秒结果提示，再恢复实际剩余流量出口摘要。控制面板提供 `⌘0` 菜单快捷入口，默认窗口为 900 × 640。

已通过 macOS 构建和部分界面点击检查。独立本地代理链完成过单次 UDP DNS 往返；真实 TUN、公司 VPN 共存和应用流量匹配尚未验收。表单中的 SOCKS5 UDP 探测仅检查 UDP ASSOCIATE 握手，不能等同于端到端 UDP 可用。

### 交互优化实施记录（2026-11-17）

菜单栏、日志页和退出流程按第 3、9 节补齐。菜单栏显示当前状态与最近错误摘要，提供启动/停止、检查配置（运行中为「重新检查配置」）、查看日志、代理出口、打开控制面板、打开配置和退出；「查看日志」「代理出口」直接切到对应页面再打开控制面板。代理运行中选择「退出」先弹出确认，确认后停止 sing-box 再退出；未运行时立即退出。

底部状态栏的错误摘要现在同时切换到日志页并选中 Warning/Error 筛选。此前只切页不改筛选，而失败文本本身不含 `error`/`fatal`/`warning` 字样，用户会落到「没有匹配的日志」。为此所有写入日志的失败统一带 `ERROR` 前缀，运行时版本不匹配也记入日志，保证错误入口总能定位到对应行。

日志页新增「自动滚动到底部」开关与「回到最新」按钮、行数统计，以及 `outbound/chatgpt-vless`、`outbound/direct`、`inbound/tun`、`FATAL`、`ERROR` 五类行内高亮。筛选与搜索逻辑移入控制器，由回归脚本覆盖。

管理员授权不再阻塞界面：`runAppleScript` 移到后台队列，启动/停止期间状态栏和菜单栏可继续绘制，`正在启动…`/`正在停止…` 与禁用态可见。顺带删除从未赋值的 `process`/`outputPipe` 分支，`isRunning` 只依据 PID 文件与 `privilegedPID`；`refreshStatus` 会在进程消失时把 `.stopping` 归位到 `.stopped`。

已通过 Debug 构建、回归脚本与真实窗口操作：错误摘要入口（filter 预选 + 2 行 ERROR 可见）、菜单栏两项页面跳转、自动滚动开关与「回到最新」、版本门拦截启动、未运行态退出。运行态退出确认与管理员授权的界面响应耗时未在本次验证。

### 运行时版本门调整（2026-11-17）

版本门从“精确匹配 1.14.0”改为“最低版本 1.14.0”。设置页状态文案随之改为“版本满足最低要求”，运行时区块展示实际版本（例如 `sing-box：1.14.4（内置）`）而不是固定写 1.14.0。低于基线或无法解析版本时，状态显示“运行时损坏或版本过低”并禁用启动；高于基线正常放行，代理启动前仍执行 `check`。Debug 选择按钮改名为“选择 sing-box（不低于 1.14.0）…”。

## 7. 公司 VPN 页面

页面顶部提供“重新检查 VPN”。每个客户端使用独立状态卡：

当前实现提供共享的 TUN 显式排除列表编辑器。每张卡可将未被现有 CIDR 覆盖的预设检测目标预填到完整列表中，用户检查后再保存；目标全部被覆盖时按钮禁用。该操作不推断接口归属，也不把网段永久绑定到某个客户端。

完整线框：

```text
公司 VPN                                          [重新检查]
只检测客户端、接口和公司网段，不控制 VPN 连接

│                         [添加公司网段] [查看候选接口]     │

┌ aTrust ───────────────────────────────────────── ● 已连接 ┐
```

“添加公司网段”打开 CIDR 输入窗口。保存前校验格式，并明确说明该操作只让流量绕过 sing-box，最终出口仍由 macOS 系统路由决定。

## 8. 设置页面

设置页包含：

- 检查 sing-box 配置及显示实际可执行文件、固定版本和配置文件路径。
- 打开配置文件和配置目录。
- 查看历史配置及恢复结果。
- 后续可加入登录后启动和自动启动代理选项，MVP 不默认开启。

完整线框：

```text
设置

运行时
Conductor 1.0             sing-box 1.14.0（内置）  ● 正常
应用内路径：…/Conductor.app/Contents/Resources/bin/sing-box
                                      [检查 sing-box]

配置文件
~/sing-box/config.json
                              [打开文件] [打开目录]

历史配置
2026-09-12  导入 VLESS     检查通过          [查看] [恢复]
2026-09-06  添加代理出口   检查通过          [查看] [恢复]
```

检查操作不改变代理运行状态。恢复按钮在代理运行期间禁用；恢复确认框显示备份时间、变更来源以及“恢复前将备份当前配置”。

正式安装版本的运行时区域显示：

```text
Conductor：1.0
sing-box：1.14.4（内置）
运行时状态：版本满足最低要求
配置：~/sing-box/config.json
```

如果内置文件丢失、不可执行、版本低于 1.14.0 或无法解析，显示“运行时损坏或版本过低”，禁用启动代理，并提供“复制诊断信息”和“重新安装说明”。更高版本正常显示为满足要求。应用不自动安装或替换二进制。

Homebrew 安装提示使用：

```bash
brew install --cask hyfly233/conductor/conductor
```

版本升级由 `brew upgrade --cask conductor` 完成。升级过程不删除 `~/sing-box`、配置历史或偏好设置；界面不承诺应用内自动更新。

历史配置列表显示备份时间、变更来源和检查状态。恢复操作先展示影响摘要，再备份当前配置、检查待恢复配置并替换；任一步失败都保留当前配置。

## 9. 日志页面

日志页面显示最近日志，按时间倒序或原始顺序展示均可，但需要保留时间和级别。

完整线框：

```text
日志       [全部 ▾] [搜索日志                ] [复制] […]
┌───────────────────────────────────────────────────────────┐
│ 23:56:39 INFO   sing-box 1.14.4 已启动                    │
│ 23:56:40 VLESS  ChatGPT → chatgpt-vless                   │
│ 23:56:42 DIRECT 10.247.53.8 → 系统路由                    │
│ 23:56:45 ERROR  vpn-proxy-01 端口不可连接                 │
└───────────────────────────────────────────────────────────┘
自动滚动到底部 [✓]                         [打开原始日志]
```

默认保持原始时间顺序并自动滚动到底部；用户向上滚动后暂停自动滚动，并显示“回到最新”。搜索只影响当前显示，不修改文件。`…` 菜单包含清空当前显示和打开日志目录。

重点突出：

- `outbound/chatgpt-vless`
- `outbound/direct`
- `inbound/tun`
- `FATAL`
- `ERROR`

提供：

- 清空当前显示内容
- 复制日志
- 打开日志文件所在目录
- 按全部、VLESS、本地代理、公司 VPN、Direct、Warning/Error 筛选

日志页面不显示完整 UUID、私钥等敏感字段。

清空当前显示不删除磁盘日志。可读摘要与原始日志分层展示，诊断结论必须能回溯到原始日志或系统路由检查结果。

## 10. 配置对象与状态来源

控制面板展示三类对象，但公司 VPN 不属于代理出口，也不出现在配置页：

| 出口 | 管理方式 | 状态来源 |
| --- | --- | --- |
| VLESS | 由 sing-box 使用 | sing-box 日志和连接状态 |
| 本地代理端口 | 用户填写 SOCKS5/HTTP 地址和端口，或选择混合端口探测 | TCP、协议及可选 UDP 能力检查 |
| 公司 VPN | 公司 VPN 页只读展示 | 系统路由和接口信息 |

添加端口型 VPN 工具时填写名称、协议、地址、端口和可选认证信息。Conductor 不负责启动或登录该工具。

每个端口型出口可以绑定域名、IP/CIDR、应用进程名或进程路径规则。规则从上到下匹配，并显示当前顺序。

### 10.1 通用状态和视觉规范

| 状态 | 图标和颜色 | 文案要求 |
| --- | --- | --- |
| 正常/可连接 | 绿色圆点 | 同时显示“正常”“可连接”或延迟 |
| 未测试/未确认 | 灰色圆点 | 不得表达为失败 |
| 检查中 | 进度图标 | 禁止重复触发同一检查 |
| 警告 | 黄色三角 | 提供影响范围和下一步 |
| 失败 | 红色感叹号 | 提供详情和日志入口 |

卡片使用系统背景、圆角和轻边框，不复刻 V2BOX 的移动端高饱和色块。协议标签可以使用强调色，但不能成为唯一的协议识别方式。

## 11. 导入 VLESS 节点

控制面板提供“导入 VLESS Reality”输入框、目标应用选择和“导入”按钮。用户粘贴原始 `vless://` URI 并选择“ChatGPT”后，应用解析参数，生成临时配置并执行 `sing-box check`。检查成功后备份原配置，更新 ChatGPT 绑定的 outbound 和路由规则，用户重新启动代理后生效。

运行中的代理禁止导入。当前入口要求 scheme 为 `vless`、security 为 `reality`，并要求包含 `flow`、`sni`、`fp`、`pbk` 和 `sid`；不会修改 TUN、DNS、公司网段和其他应用规则。失败时原配置保持不变。

导入成功只显示服务器地址和端口，不显示完整 UUID、公钥或其他敏感参数。

导入完成后显示绑定摘要：

```text
目标应用：ChatGPT
主进程：/Applications/ChatGPT.app/Contents/MacOS/ChatGPT
域名范围：ChatGPT/OpenAI
出口：chatgpt-vless
状态：待重启代理
```

## 12. 出口不可用处理

匹配到的本地代理端口不可用时，记录失败、显示出口异常，并保持该规则的失败结果；不自动切换到 VLESS 或直连。

## 13. 配置入口

MVP 点击“打开配置”直接使用 macOS 默认编辑器打开配置文件。应用不在首期提供完整 JSON 编辑器，避免重复实现 sing-box 配置校验。

配置修改后，用户点击“重新检查配置”；运行中的配置不会自动热重载，避免编辑过程中破坏现有连接。检查成功后提示用户重启代理使配置生效。

“检查 sing-box”同时检查内置文件存在性、可执行权限、实际版本和配置兼容性。显示的检查结果必须包含实际二进制路径，避免误用 `/opt/homebrew/bin/sing-box` 或 `/usr/local/bin/sing-box`。

## 14. 错误提示

错误提示应包含三个部分：

```text
发生了什么
可能原因
下一步操作
```

示例：

```text
sing-box 无法启动 TUN。
可能原因：V2Box 仍在运行 TUN 模式，或 macOS 网络扩展发生冲突。
请先关闭 V2Box 的 TUN/VPN 模式，然后重新启动。
```

最低版本错误示例：

```text
无法启动代理。
当前运行时低于 Conductor 1.0 要求的 sing-box 1.14.0。
请通过 Homebrew 重新安装或升级 Conductor；现有配置不会被删除。
```

## 15. 无障碍与一致性

- 使用系统菜单栏、按钮、状态颜色和文字同时表达状态。
- 错误不能只使用红色表示。
- 所有操作支持键盘访问。
- 长日志支持滚动和复制。
- 所有图标按钮都有 tooltip 和无障碍标签。
- 键盘焦点顺序按照顶部导航、页面主操作、内容卡片、底部状态栏排列。
- 支持窗口缩放；达到最小宽度后页面内容垂直重排，不出现水平滚动条。
