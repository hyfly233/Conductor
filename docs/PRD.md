# Conductor 产品需求文档

## 1. 文档信息

- 产品名称：Conductor
- 平台：macOS
- 产品形态：个人自用菜单栏应用
- 当前阶段：MVP 设计
- 文档状态：原型方案待确认

## 2. 背景与问题

当前设备同时使用 OpenVPN、EasyConnect 和 aTrust，公司 VPN 通过系统级 VPN 接口提供公司内网访问；另有 VLESS 节点用于访问 ChatGPT 等服务。现有 V2Box 可以连接 VLESS，但规则、TUN 状态和公司 VPN 共存需要手工维护。

Conductor 的目标是提供一个轻量的 macOS 控制入口，由 sing-box 负责流量接管和转发，Conductor 负责配置管理、启动停止、状态展示和故障提示。

## 3. 产品目标

### 3.1 MVP 目标

实现以下稳定可验证的行为：

1. ChatGPT 桌面应用及 OpenAI/ChatGPT 相关域名走 VLESS Reality。
2. 公司 VPN 继续由 OpenVPN、EasyConnect、aTrust 自己维护，公司网段保留原有系统路由。
3. 其他流量默认直连。
4. 用户可以从菜单栏启动、停止和查看 sing-box 状态。
5. 启动前自动检查配置，错误时展示可读提示。
6. sing-box 日志可以查看最近内容，便于确认实际出口。
7. 支持登记提供本地 SOCKS5/HTTP 或混合端口的 VPN 工具，并将指定流量转发到该端口。
8. 支持粘贴 VLESS Reality URI，并将其绑定到 ChatGPT 应用及相关域名。
9. 提供“配置、公司 VPN、设置、日志”四个独立页面，避免节点、系统 VPN 和诊断操作混在同一界面。
10. Conductor 1.0 要求 sing-box 不低于 1.14.0，发布物内置 1.14.0，避免无意升级导致配置格式或路由行为变化。
11. 支持通过 Homebrew Cask 安装和升级 Conductor。

### 3.2 后续目标

- 通过配置界面维护域名、IP/CIDR 和进程规则。
- 支持导入/导出 sing-box 配置。
- 管理多个本地代理端口型 VPN 工具。
- 监测公司 VPN 接口和公司路由变化。
- 支持开机启动和异常退出恢复。

## 4. 非目标

MVP 不实现以下能力：

- 自研 VLESS、Reality、TUN 或 VPN 协议。
- 直接控制 OpenVPN、EasyConnect、aTrust 的认证和连接过程。
- 将没有 SOCKS5/HTTP 端口的公司 VPN 转换为代理出口。
- 直接控制端口型 VPN 工具的登录、连接和断开。
- 通过远程服务获取或上传节点配置。
- iOS、Windows 或 Linux 支持。
- 云端同步、账号系统或多用户配置。

## 5. 目标用户与典型场景

目标用户是能够在 macOS 上使用终端和 VPN 客户端的个人开发者。

典型场景：

```text
打开电脑
  ↓
公司 VPN 已连接
  ↓
从菜单栏启动 Conductor
  ↓
Conductor 启动 sing-box TUN
  ↓
ChatGPT → VLESS；公司网段 → 公司 VPN；其他 → 直连
```

## 6. 功能需求

### 6.1 菜单栏状态

菜单栏显示当前总体状态：

- 未运行
- 启动中
- 运行中
- 配置错误
- 运行异常

菜单栏至少提供：

- 启动
- 停止
- 打开配置
- 查看日志
- 重新检查配置
- 退出应用

### 6.2 sing-box 生命周期

Conductor 应能够：

- 检查 sing-box 可执行文件是否存在。
- 检查配置文件是否存在。
- 执行 `sing-box check`。
- 启动 `sing-box run`。
- 读取标准输出和标准错误。
- 检测进程退出并更新状态。
- 停止由 Conductor 启动的 sing-box 进程。

Conductor 1.0 随应用包内置 sing-box 1.14.0，作为最低版本基线。正式安装版本只使用内置运行时，不依赖用户另外执行 `brew install sing-box`，也不自动调用 Homebrew Core 中可能变化的 sing-box。开发构建可以显式配置外部二进制路径（版本不得低于 1.14.0），但必须标记为开发模式，且不得静默替代内置版本。

### 6.3 路由配置

配置至少支持以下出口：

| 出口 | 作用 |
| --- | --- |
| `chatgpt-vless` | VLESS Reality 节点 |
| `vpn-proxy-*` | 本地或远端 SOCKS5/HTTP 代理；界面可对混合端口自动探测协议 |
| `direct` | 系统直连，继续使用系统已有公司路由 |

MVP 路由规则：

- ChatGPT 应用进程 → `chatgpt-vless`
- ChatGPT/OpenAI 域名 → `chatgpt-vless`
- 用户指定的域名、IP/CIDR 或应用进程 → 对应 `vpn-proxy-*`
- 指定公司网段 → 从 sing-box TUN 排除，交给 OpenVPN、EasyConnect、aTrust 的系统路由
- 选择本地代理为“剩余流量”出口后，其他未匹配流量 → 该本地代理（端点预填 `127.0.0.1:7890`）
- 未配置剩余流量出口时，其他流量 → `direct`

### 6.4 代理出口管理

用户可以用 `IP/主机:端口` 添加 SOCKS5、HTTP 或“混合端口”代理出口：名称、协议、端点、可选认证信息和启用状态。代理可以位于本机或远端；Conductor 负责协议探测、端口检查、配置生成和状态展示，不负责代理工具自身的登录、连接和重连。

添加本地代理时，端点预填 `127.0.0.1:7890`，但不绑定 FastLink 产品名称，也不固定 outbound tag。用户填写出口名称，并选择 SOCKS5、HTTP 或混合端口。默认选择“剩余流量”；保存后将 `route.final` 设置为用户填写的出口 tag，ChatGPT、公司网段、DNS 等更高优先级规则保持不变。

“混合端口”是 Conductor 的自动探测模式，不是 sing-box outbound 类型。保存前分别执行 HTTP CONNECT 和 SOCKS5 CONNECT 探测；只允许在至少一种协议验证成功后生成配置。两种协议均可用时优先生成 SOCKS5 outbound，并继续检查 SOCKS5 UDP 能力；仅 HTTP 可用时生成 HTTP outbound。配置卡片显示实际采用的协议，不能显示不存在的 `mixed` outbound。

HTTP 出口或不支持 SOCKS5 UDP 的出口不能承载 QUIC 等 UDP 流量。界面必须显示“仅 TCP”状态和影响说明；当该出口承接剩余流量时，默认生成 UDP/443 快速拒绝规则，使浏览器立即回退 TCP，避免日志持续出现 `UDP is not supported by outbound` 和多次约 300 ms 等待。显式命中 ChatGPT VLESS、公司网段和 VPN 客户端防回环规则的流量优先于该回退规则。

当代理端点位于本机时，用户可以选择提供该端口的 VPN `.app`。Conductor 扫描应用包内 `Contents/MacOS` 可执行文件，为路径和进程名生成高优先级 `direct` 规则，避免 VPN 客户端自身的上游连接再次进入本地代理而形成代理回环。未选择应用时允许保存，但必须醒目提示风险。

### 6.5 配置安全

编辑已有出口时保留认证及高级参数和组合条件路由；表单按所选范围替换对应的简单域名、IP 或应用路径规则，其他范围保留。选择剩余流量时保留已有显式规则。混合模式编辑后仍保持自动探测。操作反馈应显示保存结果和实际默认出口，不能使用固定节点文案代替当前配置状态。

- 不在日志中打印 UUID、Reality 私钥或完整敏感配置。
- 配置文件权限应限制为当前用户可读写。
- 导入配置时不自动执行任意 shell 命令。
- 用户之前公开过的 UUID 应更换后再写入正式配置。

### 6.6 VLESS URI 导入

用户可以在控制面板粘贴 `vless://` URI，并将节点绑定到 ChatGPT。MVP 支持 VLESS Reality 节点，解析并更新 `chatgpt-vless` 出站，同时生成 ChatGPT 进程、辅助进程和 OpenAI/ChatGPT 域名的路由规则。

导入流程必须先生成临时配置并执行 `sing-box check`，检查成功后才替换正式配置；替换前保留原配置备份。代理运行中不允许导入，避免运行中的配置与磁盘配置不一致。

URI 中的 UUID、Reality 公钥和其他敏感参数不进入普通日志。格式错误、缺少必要参数、非 Reality 节点或配置检查失败时，保留原配置并显示错误。

### 6.7 节点与应用绑定

ChatGPT 绑定包含主进程路径、辅助进程规则、OpenAI/ChatGPT 域名集合和对应的 outbound tag。导入或替换 ChatGPT 节点时，只更新该绑定的 outbound 和规则，不改变公司网段、其他应用和默认直连规则。MVP 暂不支持在界面中创建其他应用模板。

### 6.8 控制面板信息架构

控制面板使用四个一级页面：

| 页面 | 职责 |
| --- | --- |
| 配置 | 管理 VLESS 节点、SOCKS5/HTTP/混合端口出口及其流量绑定 |
| 公司 VPN | 检测 OpenVPN、EasyConnect、aTrust 的接口、系统路由和公司网段 |
| 设置 | 管理 sing-box 路径、配置文件、启动行为和历史配置 |
| 日志 | 查看、筛选和复制运行日志及可读诊断摘要 |

代理运行状态和启动/停止入口在所有页面保持可见。菜单栏继续提供最常用的启停、检查和打开控制面板操作。

控制面板是面向 macOS 桌面的独立窗口，建议最小尺寸为 760 × 540 pt，默认尺寸为 900 × 640 pt。窗口结构固定为：顶部标题与一级导航、中部页面内容、底部运行状态栏。内容区域可以滚动，但导航和运行状态栏不能随内容滚动消失。

### 6.9 配置列表与流量范围

配置页用卡片展示出口，至少包含类型、名称、脱敏地址、连通状态、绑定摘要、测试和编辑操作。VLESS 卡片可展示延迟；本地端口型出口展示端口连通结果。

“第三方 VPN 配置 `127.0.0.1:7890`”属于本地代理出口，不属于公司 VPN。新增配置支持：

- 导入 VLESS Reality URI。
- 添加 SOCKS5 出口。
- 添加 HTTP 出口。
- 添加混合端口出口并自动探测实际协议。

每个出口的流量范围可选择指定应用、指定域名或指定 IP/CIDR。全局流量模式可以保留为高级选项，但必须提示它会改变默认出口，并可能影响公司 VPN；MVP 不默认启用全局模式。

配置卡片必须区分“启用状态”和“健康状态”：启用表示规则会被写入配置，健康表示最近一次测试结果。未测试不能显示为不可用；应显示“未测试”。运行代理期间允许测试和查看详情，但修改、删除、导入及变更绑定必须禁用，并提示停止代理后操作。

### 6.10 公司 VPN 检测与网段

公司 VPN 页面分别展示 OpenVPN、EasyConnect、aTrust 的检测结果：连接状态、当前接口、已登记公司网段以及系统路由结果。用户可以添加、编辑和删除公司网段；这些网段用于绕过 sing-box TUN，最终仍由 macOS 系统路由选择公司 VPN。

当前实现提供共享的 TUN 排除列表编辑，不记录网段与单个客户端的归属；卡片上的固定网段仅是检测目标，不证明客户端连接或网段归属。公司 VPN 的真实接口与路由共存仍需现场验收。

不能永久依赖 `utun8`、`utun10`、`utun11` 等编号识别客户端，因为重连或重启后编号可能变化。检测结果不等同于控制 VPN 客户端，Conductor 不负责登录、启动或断开公司 VPN。

公司 VPN 卡片的“已连接”只能在有当前接口或目标网段路由证据时显示。只有发现客户端进程但没有可验证路由时，应显示“客户端运行，连接状态未知”。

### 6.11 设置与历史配置

设置页提供：检查 sing-box、打开配置文件、打开配置目录，以及查看历史配置。每次由 Conductor 写入正式配置前都保留备份，并记录时间、变更来源和配置检查结果。

恢复历史配置前必须再次备份当前配置，并对待恢复版本执行 `sing-box check`；失败时不得覆盖当前配置。

### 6.12 日志与诊断

日志页保留原始 sing-box 日志，并支持按全部、VLESS、本地代理、公司 VPN、Direct 和 Warning/Error 筛选。界面可在原始日志之上生成不含敏感字段的可读摘要，但不得篡改或替代原始日志。

日志页提供复制、清空当前显示和打开日志文件。清空显示不删除磁盘历史日志，除非用户明确执行删除操作。

#### 6.12.1 空状态和操作反馈

- 没有代理配置时，配置页展示用途说明和“新增配置”，不显示空白列表。
- 未登记公司网段时，公司 VPN 页仍展示检测到的客户端和候选接口，并引导添加网段。
- 没有日志时展示“启动代理后将在这里显示日志”。
- 保存成功、检查成功等结果使用短暂非阻塞提示；配置覆盖、删除和全局代理等高影响操作需要确认。
- 所有失败都保留用户输入，并提供原因和下一步操作。

### 6.13 最低运行时版本

Conductor 1.0 的兼容基线为 sing-box 1.14.0，这是允许运行的最低版本。应用启动、检查配置和运行代理时必须使用同一个内置二进制，并展示实际版本。版本低于 1.14.0 或无法解析时禁止启动，提示重新安装或升级 Conductor；高于该基线的版本允许运行，但代理运行前仍会执行 `check`，配置不兼容时按错误处理。

sing-box 只能随 Conductor 发布版本升级。升级前必须完成配置迁移评估和回归测试，并在发布说明中标明旧版本、新版本、配置格式变化及回滚方式。

### 6.14 Homebrew 安装与升级

Conductor 通过自有 Homebrew Tap 发布 Cask，目标安装命令为：

```bash
brew install --cask hyfly233/conductor/conductor
```

Cask 安装已签名并公证的 `Conductor.app`，应用包包含对应 CPU 架构的 sing-box 1.14.0。Homebrew 负责 Conductor 的安装、升级和卸载；Conductor 不在运行时调用 `brew install`，也不修改用户已有的独立 sing-box Formula。

发布物必须提供固定版本下载地址和 SHA-256。Apple Silicon 与 Intel 可以分别发布构建，由 Cask 按架构选择；两者必须使用相同的 Conductor 和 sing-box 版本。

## 7. 验收标准

### 功能验收

- `sing-box check` 成功时可以启动 sing-box。
- ChatGPT 桌面应用请求在日志中显示为 `chatgpt-vless`。
- 指定流量在日志中显示为对应的 `vpn-proxy-*` 出口。
- 公司内网地址仍可访问，且路由指向 OpenVPN、EasyConnect 或 aTrust 对应的 `utun` 接口。
- 普通国内网站不经过 VLESS。
- 停止 Conductor 后，公司 VPN 不被停止或修改。
- sing-box 启动失败时，菜单栏显示错误原因。
- 切换四个页面时，运行状态和启停入口始终可见且状态一致。
- VLESS 与 SOCKS5/HTTP/混合端口出口在配置页展示，公司系统 VPN 不被误显示为普通代理出口。
- 公司 VPN 检测能够显示接口和指定公司网段的实际路由；无法识别时明确显示未知，不猜测接口归属。
- 历史配置恢复前后均有可恢复备份，且恢复版本通过 `sing-box check`。
- 设置页显示实际 `sing-box` 版本与内置/开发来源，配置检查和代理运行使用同一路径。
- 未安装 Homebrew Core 的 sing-box 时，Conductor 仍能检查配置和启动代理。
- 检测到运行时低于 1.14.0 或无法解析版本时禁止启动，并给出可执行的修复提示。
- `brew install --cask hyfly233/conductor/conductor` 能完成安装，应用可从 `/Applications` 启动。
- `brew upgrade --cask conductor` 不丢失用户配置、备份历史和应用设置。
- 默认窗口尺寸下，四个一级页面、固定状态栏和主要操作无需横向滚动。
- 配置卡片能同时表达协议、脱敏端点、绑定、启用状态和最近测试状态。
- 混合端口能够区分 HTTP、SOCKS5 TCP 和 SOCKS5 UDP 探测结果，并生成具体的 `http` 或 `socks` outbound。
- 仅 TCP 的剩余流量出口不会反复把 UDP/443 发送到 HTTP outbound，浏览器能够快速回退 TCP。
- 代理运行期间不能修改会改变磁盘配置的内容，但仍可查看、测试和筛选日志。

### 边界验收

- 公司 VPN 断开时，Conductor 不自动修改公司 VPN 的连接状态。
- 公司路由变化时，应用提示需要重新检查配置。
- VLESS 不可用时，ChatGPT 失败，但不影响公司内网和普通直连流量。
- 本地代理端口不可用时，明确提示出口不可用，不静默切换出口。

## 8. 风险与依赖

- macOS 多个 Network Extension/TUN 同时运行的路由行为依赖各 VPN 客户端实现。
- 公司 VPN 的网段和 DNS 可能动态变化。
- ChatGPT 桌面应用可能使用辅助进程，需要根据实际连接日志补充进程规则。
- 本地代理端口可能被占用、认证失效或只支持 TCP。
- sing-box 版本升级可能带来配置字段迁移，因此只能随经过验证的 Conductor 版本升级。
- Homebrew 发布依赖稳定的下载地址、SHA-256、代码签名和 Apple 公证。

## 9. 前端影响

有 macOS 菜单栏界面和交互变化，但不涉及 Web 前端页面。MVP 增加端口型 VPN 工具的简单管理入口和出口状态展示，不承载 VPN 工具自身的登录页面。
